# GASOK & Ecosystem Evidence Package

This directory stores verified empirical evidence from live GIWA Sepolia network tests, benchmarks, contract deployments, and integrations.

## Structure
- `benchmarks/`: Automated and manual latency benchmarks (p50, p95, early-signal advantage).
- `deployments/`: Contract deployment records on GIWA Sepolia.
- `live-tests/`: Regular RPC and network health check records.
- `integrations/`: Adoption logs and integration tests with partner apps.
- `releases/`: Release bundle verification logs.
